# Гайд: прошивка ESP32 Wind Station

> **Устарел с 2026-08-15. Актуальный документ — `FLASHING.md`.**
>
> Здесь описан первый заход через Arduino IDE, когда станция ещё заходила в домашнюю сеть.
> Сейчас рабочий путь другой: сборка через `arduino-cli`, заливка по OTA через собственную
> точку доступа платы, `arduino-cli upload` использовать нельзя (сломан автосброс).
> Файл оставлен как история первой прошивки и как справка по драйверу USB-Serial.

Пошаговая инструкция на основе реального опыта первой прошивки 2026-05-01.

---

## 1. Что нужно

- ESP32 DevKit V1 (30-pin, Type-C)
- USB-кабель **с передачей данных** (не только зарядный)
- ПК с Windows
- Arduino IDE 2.x

---

## 2. Установка Arduino IDE и пакета ESP32

1. Скачать Arduino IDE с arduino.cc, установить.
2. Открыть `File → Preferences → Additional boards manager URLs`, добавить:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. `Tools → Board → Boards Manager` → найти **esp32** от **Espressif Systems** → Install (скачивает ~200 МБ).

---

## 3. Библиотеки

Дополнительных библиотек не нужно — всё используемое (WiFi, WiFiMulti, Preferences, WebServer, ESPmDNS, ArduinoOTA, Ticker) входит в ядро ESP32.

> Раньше требовался **WiFiManager** (tzapu) — с версии 2026-08-02 он удалён из прошивки: настройка сетей теперь через дашборд (`/api/wifi`), а при отсутствии известных сетей станция поднимает свою точку доступа с тем же дашбордом.

---

## 4. Настройки платы

| Параметр | Значение |
|---|---|
| Board | `ESP32 Dev Module` |
| Upload Speed | `115200` |
| Port | COM-порт, который появляется при подключении ESP32 (у нас COM4) |

Если не знаешь какой COM-порт: подключи ESP32, зайди в Диспетчер устройств → Ports (COM & LPT) — появится новая строка.

---

## 5. Прошивка — процедура с кнопками

ESP32 DevKit V1 **не входит в режим прошивки автоматически**. Нужно помочь кнопками.

На плате две кнопки:
- **BOOT** (она же IO0) — переводит в режим загрузки
- **EN** (Reset) — перезагрузка

**Последовательность:**

1. Нажать **Upload** в Arduino IDE
2. Дождаться появления `Connecting......` в консоли
3. Зажать и удерживать **BOOT**
4. Нажать и отпустить **EN**
5. Удерживать **BOOT** до появления `Writing at 0x...` — тогда отпустить
6. Дальше прошивка идёт сама, ждать `Done uploading`

> Если появилось `Wrong boot mode detected (0x13)` — значит BOOT не был зажат вовремя, повторить.

---

## 6. Serial Monitor — обязательно

После прошивки открыть `Tools → Serial Monitor`.

**Критично: скорость должна быть 115200 baud** (выпадающий список внизу справа).  
При любой другой скорости весь вывод выглядит как кракозябры — это не ошибка, просто неверный baud rate.

Нажать **EN** на плате. Ожидаемый вывод:

```
rst:0x1 (POWERON_RESET),boot:0x13 (SPI_FAST_FLASH_BOOT)
...                          ← ROM-загрузчик, кракозябры в начале — норма
=== Wind Station ===
WiFi OK
IP: 192.168.1.xxx
mDNS: http://windstation.local
OTA ready
HTTP: 80
V=0.0 m/s  D=0°  G=0.0  Bat=0.00V (0%)  RSSI=-30
```

> Кракозябры в самом начале (`rst:0x1...`) — это ROM-загрузчик ESP32 на 74880 baud. Это нормально, после них идёт читаемый текст прошивки на 115200.

## 7. Настройка WiFi

Станция хранит **до 6 сетей** (домашняя, hotspot телефона/планшета, дача…) и при загрузке или потере связи сама подключается к самой сильной из доступных.

**Добавить сеть** — на дашборде: ⚙ Настройки → «WiFi-сети станции» → ввести SSID и пароль → «+ Добавить».

**Если ни одна известная сеть не найдена** (первый запуск, чужое место) — станция поднимает открытую точку доступа:

**SSID: `WindStation-Setup`**

1. Подключиться к `WindStation-Setup` с телефона или ноутбука
2. Открыть в браузере `http://192.168.4.1` — это тот же дашборд
3. В ⚙ Настройках добавить свою сеть 2.4 ГГц (SSID + пароль)
4. В течение ~30 секунд станция найдёт сеть, подключится и выключит точку доступа

> ESP32 поддерживает **только 2.4 ГГц**. Если роутер раздаёт отдельные сети `MyWifi` и `MyWifi_5G` — выбирать без `_5G`.

**Удалить сеть** — кнопка ✕ в том же списке (из скана уходит после перезагрузки станции).

---

## 8. Проверка работы

Открыть в браузере (с любого устройства в той же сети — телефон, планшет, ноутбук):

- `http://windstation.local` (или IP станции, например `http://192.168.1.223`) — **полный дашборд**, встроен в прошивку
- `http://windstation.local/api/data` — JSON со всеми данными

Пример ответа API:
```json
{
  "speed": 0.0,
  "direction": 0,
  "gust": 0.0,
  "ledGreen": true,
  "ledYellow": false,
  "ledRed": false,
  "ledAuto": true,
  "battery": 0.00,
  "batteryPercent": 0,
  "wifiRssi": -25,
  "adcError": false,
  "hostname": "windstation.local",
  "uptime": 74
}
```

> Без подключённого датчика `speed` и `direction` покажут шум (~4 м/с, ~26°) — это нормально, плавающие ADC-пины. После подключения датчика с 0V на входе будет 0.0 м/с.

---

## 9. OTA — следующие прошивки по WiFi

После первой прошивки по USB все последующие можно заливать **по воздуху**:

`Tools → Port → Network Ports → windstation`  
→ Upload (кнопки BOOT/EN не нужны)

OTA-пароль: `SECRET_OTA_PASSWORD` в `esp32_wind_station/secrets.h` (файл вне git)

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `Write timeout` | ESP32 не в режиме загрузки | Держать BOOT при `Connecting...` |
| `Wrong boot mode (0x13)` | BOOT отпущен слишком рано | Повторить: BOOT → EN → держать BOOT до `Writing at...` |
| Только кракозябры в Serial Monitor | Неверный baud rate | Поставить 115200 |
| `WindStation-Setup` не появляется | ESP32 нашёл сохранённую сеть | Нормально, подключился автоматически |
| `speed: 4.3` без датчика | Плавающий ADC-пин | Норма, исчезнет после подключения датчика |
