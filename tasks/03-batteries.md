## Цель
Проверить заряд батарей и собрать параллельный пакет из 2×18650.

## Компоненты
| Компонент | Кол-во |
|-----------|--------|
| 18650 LG | 2 |
| Холдер 18650 одинарный | 2 |
| Мультиметр UT33A+ | 1 |

## Полярность 18650
```
    ──────────────────
   │  (−) плоский     │  ← МИНУС: плоский торец
    ──────────────────
   │                  │
   │   LG / Samsung   │
   │                  │
    ──────────────────
   │  (+) с бугорком  │  ← ПЛЮС: торец с маленьким выступом
    ──────────────────
```

## Шаг 1 — Измерить напряжение каждой батареи

Мультиметр UT33A+ (авторежим, повернуть в положение **V⎓**):
- Красный щуп → плюс (+, бугорок)
- Чёрный щуп → минус (−, плоский торец)

| Результат | Статус | Действие |
|-----------|--------|---------|
| 3.5 – 4.2V | ✅ Норма | Использовать |
| 3.0 – 3.5V | ⚠️ Разряжена | Использовать, но зарядить при первой возможности |
| < 3.0V | ❌ Глубокий разряд | Не использовать — TP4056 её не примет |
| > 4.25V | ❌ Перезаряд | Не использовать |

Запиши напряжение каждой батареи:
- Батарея 1: ______V
- Батарея 2: ______V

> Обе батареи должны быть близки по напряжению (разница < 0.1V).
> Если разница > 0.3V — при параллельном соединении более заряженная
> будет заряжать менее заряженную, пойдёт ток выравнивания. Это допустимо,
> но лучше предварительно зарядить обе до одинакового уровня.

## Шаг 2 — Вставить батареи в холдеры

В каждом холдере на дне выдавлена разметка `+` и `−`.
- Бугорок батареи (+) → к маркировке `+` (пружина или контакт с точкой)
- Плоский торец (−) → к маркировке `−` (пружина)

После вставки измерь напряжение на проводах каждого холдера:
- Красный провод холдера = `+`
- Чёрный провод холдера = `−`
- Должно совпадать с напряжением батареи.

## Шаг 3 — Соединить холдеры параллельно

```
Холдер 1:  красный (+) ──┬── красный (+)  :Холдер 2
           чёрный  (−) ──┴── чёрный  (−)

                     ↓
              Пакет батарей:
              красный (+)  = общий плюс
              чёрный  (−)  = общий минус
```

Соединение: красный провод холдера 1 → красный провод холдера 2 (скрутить или через dupont).
То же для чёрных проводов.

> ⚠️ Красный к красному, чёрный к чёрному — без вариантов.
> Перепутать полярность при параллельном соединении = КЗ, искра, сгоревший холдер.

## Шаг 4 — Измерить пакет

Красный щуп → объединённый красный провод, чёрный → объединённый чёрный.
Ожидание: то же напряжение что и у отдельных ячеек (параллель = одинаковое напряжение, удвоенная ёмкость).

Запиши: ______V — это рабочее напряжение пакета.
