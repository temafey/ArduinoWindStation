## Цель
Подключить делитель для мониторинга напряжения батареи на GPIO32.
После этого поле `battery` в `/api/data` покажет реальное напряжение батареи.

## Компоненты
| Компонент | Кол-во | Цвет полос |
|-----------|--------|-----------|
| Резистор 100kΩ | 2 | коричневый-чёрный-жёлтый-золотой |
| Конденсатор керамика 100нФ (маркировка «104») | 1 | маленький «леденец» |

## Схема

```
Батарея (+) после предохранителя
        │
      [100kΩ]   ← R1 (верхнее плечо)
        │
        ├──── GPIO32 (ADC1, пин D32 на ESP32)
        │
        ├──── [100нФ] ──── GND   ← фильтр помех
        │
      [100kΩ]   ← R2 (нижнее плечо)
        │
       GND
```

## Математика (для понимания)
```
V_GPIO32 = V_bat × R2 / (R1 + R2) = V_bat × 100k / (100k + 100k) = V_bat × 0.5

Прошивка: V_bat = V_GPIO32 × BATTERY_DIVIDER_RATIO = V_GPIO32 × 2.0

При батарее 4.0V → GPIO32 = 2.0V → /api/data: "battery": 4.0  ✓
При батарее 3.7V → GPIO32 = 1.85V → /api/data: "battery": 3.70 ✓
```

## Подключение на breadboard

1. R1 (100kΩ): один вывод → шина батареи (+), второй вывод → ряд X
2. R2 (100kΩ): один вывод → ряд X, второй вывод → GND
3. Конденсатор 100нФ (104): один вывод → ряд X, второй → GND (полярности нет)
4. Провод: ряд X → GPIO32 (пин D32 на ESP32)

> ⚠️ GPIO32 — это **ADC1**, только аналоговый вход.
> НЕ путай с GPIO32 как цифровым — в прошивке он читается через `analogReadMilliVolts(PIN_BATTERY)`.

## Проверка

**Шаг 1.** Измерь мультиметром реальное напряжение батареи:
- Красный щуп → батарея (+), чёрный → GND
- Запиши: V_bat = ______V

**Шаг 2.** Измерь на пине GPIO32:
- Красный щуп → пин D32 ESP32, чёрный → GND
- Ожидание: примерно V_bat / 2
- Запиши: V_GPIO32 = ______V

**Шаг 3.** Открой в браузере:
```
http://windstation.local/api/data
```
Поле `"battery"` должно быть ≈ V_bat (то что измерил в шаге 1).
Поле `"batteryPercent"`: 0% = 3.5V, 100% = 4.2V.

## Ожидаемые значения
| V_bat (измерен) | V_GPIO32 | "battery" в API | "batteryPercent" |
|----------------|----------|-----------------|-----------------|
| 4.20V | 2.10V | 4.20 | 100% |
| 4.00V | 2.00V | 4.00 | 71% |
| 3.70V | 1.85V | 3.70 | 29% |
| 3.50V | 1.75V | 3.50 | 0% |

## Если не работает
| Симптом | Причина | Решение |
|---------|---------|---------|
| battery = 0.00 в API | Делитель не подключён к батарее+ | Проверь R1 идёт к батарее, не к RAIL |
| battery = 9.xx (двойное) | R2 не подключён к GND | Проверь нижний резистор |
| battery = правильно, но скачет | Нет конденсатора 100нФ | Добавь фильтр |
| batteryPercent всегда 0 | Батарея < 3.5V | Зарядить или норм — это и есть 0% |
