## Цель
Перенести собранную схему из макетки в постоянный монтаж в IP65 корпус 190×150×75.

## Компоненты финальной сборки
| Компонент | Примечание |
|-----------|-----------|
| Корпус IP65 190×150×75 | Сверлить: сверло 12мм × 2 отверстия под PG7 |
| Гермоввод PG7 × 2 | Кабель датчика + кабель адаптера |
| Герметик Lacrysil | Периметр крышки после финальной проверки |
| PPTC 2A radial | Заменить временный SMD-предохранитель |
| Монтажная лента PROзапас | Крепление плат внутри корпуса |
| Стяжки | Организация проводов |
| Термоусадка | Изоляция соединений |

## Последовательность
1. Разметить и просверлить отверстия под PG7 (сверло 12мм)
2. Установить гермовводы PG7
3. Прокинуть кабели через гермовводы
4. Перепаять схему на постоянную проводку (убрать breadboard)
5. Заменить временный предохранитель на radial PPTC 2A
6. Закрепить компоненты монтажной лентой
7. Финальный тест всех функций через открытую крышку
8. Герметизировать крышку Lacrysil
9. Установить на мачту (мачта у сына дома)
