# Задача 04: Силовая шина (diode-OR)

## Промпт для новой сессии
```
Читай tasks/04-power-rail.md и выполни задачу шаг за шагом.
Источники истины: CLAUDE.md, bom-photos.md.
```

## Статус
- Блокеры: нет (задачи 02 и 03 должны быть выполнены)
- Предыдущие задачи: 02 (boost настроены), 03 (батареи готовы)

## Цель
Собрать полную силовую цепь на breadboard и убедиться что шина держит ~4.7V от адаптера и от батареи.

## Архитектура питания

```
USB-C адаптер 5V
      │
      ▼
TP4056 USB-C порт
      │
   IN+ пятачок ──┬─── провод → анод Schottky_A (→катод) ──── ШИНА ~4.7V
                 │                                                 │
                 └─── (внутри TP4056: заряжает батарею)            │
                              │                                    │
                         TP4056 B+ ─── [предохранитель*] ─── Батарея
                              │
                         TP4056 OUT+ → Boost#2 IN+ → Boost#2 OUT+ → анод Schottky_B (→катод) ─┘
                                               5V

* временно: SMD-предохранитель «N» 2A ИЛИ перемычка (провод)
```

**IN+ пятачок TP4056 — точка разветвления адаптера:**
- Один ток идёт внутрь модуля → заряжает батарею
- Второй ток по проводу → Schottky_A → ШИНА → питает ESP32 и сенсор

**Когда адаптер подключён — одновременно:**
- TP4056 IN+ → Schottky_A → ШИНА → ESP32 VIN + Boost#1 → сенсор 12V
- TP4056 IN+ → (внутри) → B+ → заряжает батарею

**Когда адаптер отключён:**
- Батарея → PTC → TP4056 B+ → OUT+ → Boost#2 → Schottky_B → ШИНА → ESP32 + сенсор

**Итого от ШИНЫ:**
- ШИНА → ESP32 VIN
- ШИНА → Boost#1 IN+ → Boost#1 OUT+ = 12V (питание датчика, задача 07)

|-----------|--------|-----------|

| SMD-предохранитель «N» 2A | 1 | одноразовый, временно (или перемычка) |
| Батарейный пакет | 1 | из задачи 03 |

| Мультиметр UT33A+ | 1 | |

## Идентификация 1N5819
```
  ─[======]─   серебристая полоска = КАТОД (−)
  анод      катод

Из набора диодов: цилиндр ~5×2 мм, маркировка «1N5819» на боку.
Отличие от 1N4007: 1N4007 крупнее, 1N5819 компактнее.
Нужно 2 штуки.
```

## Шаг 1 — Определить ориентацию 1N5819

Полоска на корпусе = катод = **в сторону шины** (туда течёт ток).
```
Адаптер 5V ──── [анод ▶|◀ катод] ──── ШИНА
                         ↑
               серебристая полоска
```

## Шаг 2 — Собрать схему на breadboard

**TP4056 — 6 пятачков (читай надписи на плате):**
- `IN+` / `IN−` → USB 5V адаптер (зарядка)
- `B+` / `B−` → батарейный пакет (через SMD-предохранитель на B+)
- `OUT+` / `OUT−` → Boost#2 IN+/IN−

**Schottky_A (от адаптера):**
- Анод → то же место где IN+ TP4056 (общий + адаптера)
- Катод (полоска) → шина RAIL

**Schottky_B (от Boost#2):**
- Анод → Boost#2 OUT+
- Катод (полоска) → шина RAIL

**Электролит 1000мкФ 16V:**
- Длинная ножка (+) → шина RAIL
- Короткая ножка (−) → GND шина

**SMD-предохранитель «N»:**
- Впаять 2 тонких проводка (AWG28 или ножки резистора) к двум контактным площадкам
- Включить последовательно между батарея+ и TP4056 B+

> ⚠️ Электролит: перепутать полярность = через несколько секунд вздуется.
> Длинная ножка ВСЕГДА к плюсу.

## Шаг 3 — Проверка с адаптером

1. Подключи USB адаптер, батарею НЕ подключай.
2. Мультиметр V⎓: щупы на RAIL (красный) и GND (чёрный).
3. Ожидание: **4.6 – 4.8V**

Если TP4056 мигает красным LED — нормально, это индикатор зарядки (ищет батарею).

## Шаг 4 — Проверка с батареей (без адаптера)

1. Отключи USB адаптер.
2. Подключи батарейный пакет к B+/B− TP4056.
3. Мультиметр V⎓ на RAIL / GND.
4. Ожидание: **4.6 – 4.8V** (Boost#2 поднимает 3.7V батареи до 5V, через Schottky_B падает 0.3V → ~4.7V)

## Шаг 5 — Проверка ESP32 от шины

1. Подключи RAIL → ESP32 VIN, GND → ESP32 GND (НЕ через USB, только через VIN).
2. Ожидание: ESP32 загружается, в Serial Monitor появляется `=== Wind Station ===`.
3. Мультиметр на 3V3 пин ESP32 → должно быть **3.28 – 3.35V** (AMS1117 стабилизатор).

## Контрольные напряжения
| Точка замера | Ожидание | Допуск |
|-------------|----------|--------|
| RAIL от адаптера | 4.7V | ±0.1V |
| RAIL от батареи | 4.7V | ±0.15V |
| Boost#2 OUT+ | 5.0V | ±0.2V |
| ESP32 3V3 пин | 3.3V | ±0.05V |

## Если не работает
| Симптом | Причина | Решение |
|---------|---------|---------|
| RAIL = 0V с адаптером | Schottky_A перевёрнут | Переверни диод |
| RAIL = 3.4V с батареей | Boost#2 не работает | Проверь пресет, питание Boost#2 IN+ |
| RAIL = 5.0V с батареей | Нет Schottky_B или перевёрнут | Проверь диод_B |
| ESP32 не стартует от VIN | Нет питания или VIN < 4.3V | Проверь соединение RAIL → VIN |
| Электролит тёплый/горячий | Перепутана полярность | Немедленно отключи, переверни |
