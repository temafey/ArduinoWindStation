## Цель
Собрать два одинаковых делителя (10kΩ+5kΩ)+10kΩ для сигналов датчика ветра.
Верхнее плечо (15kΩ) собирается из **10kΩ + 5kΩ последовательно** — отдельного 15kΩ в наборе нет.
Проверить без датчика — подав 5V с шины как имитацию максимального сигнала.

## Почему большее плечо (10k+5k=15k) сверху (а не наоборот)
Датчик выдаёт 0–5V. ESP32 ADC линеен в диапазоне 0.15–2.45V (11dB режим).
```
V_GPIO = V_sensor × 10k / ((10k+5k) + 10k) = V_sensor × 0.4
При V_sensor = 5V → V_GPIO = 2.0V  ← внутри линейной зоны ✓
При V_sensor = 5V, если поставить большее плечо (10k+5k) снизу, 10k сверху → V_GPIO = 3.0V ← НЕ линейно ✗
```
Прошивка: V_sensor = V_GPIO × 2.5 (SIGNAL_DIVIDER_RATIO)

## Компоненты (на ОБА делителя)
| Компонент | Кол-во | Цвет полос |
|-----------|--------|-----------|
| Резистор 10kΩ (верх 1-й в серии + низ) | 4 | коричневый-чёрный-оранжевый-золотой |
| Резистор 5kΩ (верх 2-й в серии) | 2 | зелёный-чёрный-красный-золотой |
| Конденсатор 100нФ (104) | 2 | по одному на каждый делитель |

> Верхнее плечо каждого делителя = **10kΩ + 5kΩ последовательно** (= 15kΩ). Отдельного 15kΩ в наборе нет.

## Схема одного делителя (повторить дважды)

```
Сигнал датчика (0–5V)
        │
      [10kΩ]   ← верхнее плечо, 1-й в серии
        │
      [ 5kΩ]   ← верхнее плечо, 2-й в серии  (10k+5k = 15k)
        │
        ├──── GPIO (ADC1)
        │
        ├──── [100нФ] ──── GND
        │
      [10kΩ]   ← нижнее плечо
        │
       GND
```

**Делитель #1 (скорость):** точка соединения → GPIO34 (пин D34)
**Делитель #2 (направление):** точка соединения → GPIO35 (пин D35)

> ⚠️ GPIO34 и GPIO35 — это **input-only** пины (нет внутреннего подтяжки).
> Не подключай их к выходам — только через делитель к сигналу.

## Подключение на breadboard

### Делитель скорости (GPIO34):
1. R_top = 10kΩ + 5kΩ последовательно (в серии) = 15kΩ: свободный вывод 10kΩ → сигнал скорости (сейчас → RAIL 5V для теста), другой вывод 10kΩ соединить с выводом 5kΩ, свободный вывод 5kΩ → ряд A
2. R_bot 10kΩ: один вывод → ряд A, второй → GND
3. C 100нФ: один вывод → ряд A, второй → GND
4. Провод: ряд A → пин D34 ESP32

### Делитель направления (GPIO35):
Аналогично, но: ряд B → пин D35.

## Проверка

### Тест с 5V (имитация максимального сигнала датчика)

**Шаг 1.** Подключи вход обоих делителей к RAIL (5V шина).

**Шаг 2.** Измерь мультиметром напряжение на GPIO34:
- Ожидание: **2.0V** (5V × 0.4)
- Записать: ______V

**Шаг 3.** То же для GPIO35:
- Ожидание: **2.0V**
- Записать: ______V

**Шаг 4.** Открой `/api/data`:
- `"speed"` должна быть ≈ **60.0** (5V / 5V_max × 60 m/s)
- `"direction"` должна быть ≈ **360** (5V / 5V_max × 360°)

### Тест с 0V (имитация нулевого сигнала)

**Шаг 5.** Переключи вход делителей на GND (0V).
- Ожидание: GPIO34 и GPIO35 ≈ 0V
- `/api/data`: `"speed"` ≈ 0.0, `"direction"` ≈ 0

> После теста отключи входы делителей от RAIL и GND — оставь свободными.
> При подключении датчика (задача 07) входы соединятся с сигнальными проводами датчика.

## Ожидаемые значения API при разных входах
| V_вход | V_GPIO | "speed" | "direction" |
|--------|--------|---------|-------------|
| 5.0V (RAIL) | ~2.0V | ~60.0 | ~360 |
| 2.5V (половина) | ~1.0V | ~30.0 | ~180 |
| 0V (GND) | ~0V | ~0.0 | ~0 |

> Небольшие отклонения от идеала нормальны — ADC ESP32 имеет погрешность ±50–100мВ.

## Если не работает
| Симптом | Причина | Решение |
|---------|---------|---------|
| V_GPIO = V_вход (нет деления) | R_bot не подключён к GND | Проверь нижний резистор |
| V_GPIO ≈ 0V при входе 5V | R_top не подключён к входу | Проверь верхний резистор |
| speed/direction = 0 всегда | GPIO34/35 не подключены к делителю | Проверь провода к D34/D35 |
| adcError = true в API | Оба канала < 10мВ более 30 сек | Нормально при незаключённых входах |
