## Порядок выполнения

```
Железо:  01 ✅ → 02 ✅ → 03 ✅ → 04 ✅ → 05 ✅ → 06 ✅ → 07 ✅
KiCad:   09 (документация электрики, независимо от железа)
4G/GPS:  10 (шаг 0a — AT-тест по USB, без паяльника) → 08 (корпус, в самом конце)
```

> Задача 10 не трогает существующую схему до шага 1 — весь ресерч и проверка модуля
> делаются по USB, отдельно от станции. Разводка шагов 1–2 уже нарисована: `wiring-v6.html`
> («Компакт-1» — модем садится штырями прямо на макетку, кол. 36–42, наклейкой вниз; наружу
> уходят три провода к бусту №3, земля модема — перемычка `41b`→`44b`). Контакты там
> опознаются **по буквам шелкографии**,
> а не по номерам. Предыдущий вариант `wiring-v5.html` оставлен только для сравнения.

> **08 переехала в конец очереди.** Закрывать корпус до интеграции 4G — значит вскрывать его
> обратно: модем добавляет блок питания, два провода UART и две антенны, которые надо разнести
> на 10–15 см. Заодно меняется и номинал PPTC (3 А вместо 2 А — расчёт в задаче 10, §Питание).

> Задача 09 опирается на `wind-station-schematic.md` — выверенный нетлист (источник истины для схемы).
