# Задача 01: Светодиоды на макетке

## Промпт для новой сессии
```
Читай tasks/01-leds.md и выполни задачу шаг за шагом.
Источники истины: CLAUDE.md, bom-photos.md.
```

## Статус
- Блокеры: нет
- Требования: ESP32 прошит (уже сделано), WiFi подключён к HomeSSID

## Цель
Подключить все 5 светодиодов к ESP32 на макетке и убедиться что они управляются через API.

## Компоненты
| Компонент | Кол-во | Откуда взять |
|-----------|--------|-------------|
| ESP32 DevKit V1 | 1 | — |
| LED зелёный 5мм | 2 | пакет зелёных |
| LED жёлтый 5мм | 1 | пакет жёлтых |
| LED красный 5мм | 2 | пакет красных |
| Резистор 220Ω | 5 | набор резисторов |
| Breadboard 830 | 1 | — |
| Dupont M-M | ~15 шт | — |
| USB-C кабель (data) | 1 | — |

**Резистор 220Ω — цветовой код:** красный-красный-коричневый-золотой

## Назначение GPIO (из прошивки)
| GPIO | LED | Цвет | Управление |
|------|-----|------|-----------|
| 26 | Станция OK | Зелёный | API + авто |
| 27 | Ветер >5 м/с | Жёлтый | API + авто |
| 14 | Ветер >15 м/с | Красный | API + авто |
| 25 | WiFi подключён | Зелёный | только авто (горит если WiFi есть) |
| 33 | Ошибка | Красный | только авто (горит если нет WiFi или ошибка ADC) |

## Схема подключения одного LED (одинаково для всех 5)
```
ESP32 GPIO-пин
      │
   [220Ω]        ← резистор
      │
   ──►│──         ← LED: треугольник = ток слева направо
  анод  катод     длинная ножка (+) = анод, к резистору
      │           короткая ножка (−) = катод
     GND
```

## Подключение на breadboard

Воткни ESP32 посередине breadboard (антенна смотрит наружу).

| Провод | Откуда | Куда |
|--------|--------|------|
| Питание | ESP32 pin 3V3 | шина + breadboard |
| Земля | ESP32 GND (любой) | шина − breadboard |
| LED 1 (зелёный) | GPIO26 | 220Ω → анод (+, длинная ножка) → катод → GND |
| LED 2 (жёлтый) | GPIO27 | 220Ω → анод → катод → GND |
| LED 3 (красный) | GPIO14 | 220Ω → анод → катод → GND |
| LED 4 (зелёный) | GPIO25 | 220Ω → анод → катод → GND |
| LED 5 (красный) | GPIO33 | 220Ω → анод → катод → GND |

> ⚠️ Длинная ножка LED = анод (+), соединяется с резистором (к GPIO).
> Короткая ножка = катод (−), соединяется с GND.
> Перепутал — LED не светится, но ничего не сгорит.

## Проверка

**Шаг 1.** Подключи ESP32 через USB-C к компьютеру. Подожди 10 сек — ESP32 загружается и подключается к WiFi.

**Шаг 2.** Должно загореться само:
- LED на GPIO25 (зелёный) = WiFi подключён → **должен гореть**
- LED на GPIO33 (красный) = ошибка → **должен погаснуть** после подключения WiFi

**Шаг 3.** Открой в браузере (с того же WiFi):
```
http://windstation.local/api/led?auto=false&green=true&yellow=true&red=true
```
Ожидание: загорятся GPIO26 (зелёный), GPIO27 (жёлтый), GPIO14 (красный).

**Шаг 4.** Проверь по одному:
```
http://windstation.local/api/led?auto=false&green=true&yellow=false&red=false
http://windstation.local/api/led?auto=false&green=false&yellow=true&red=false
http://windstation.local/api/led?auto=false&green=false&yellow=false&red=true
```

**Шаг 5.** Вернуть в авторежим:
```
http://windstation.local/api/led?auto=true
```

## Если не работает

| Симптом | Причина | Решение |
|---------|---------|---------|
| LED не горит ни при каких командах | Перепутана полярность | Переверни LED |
| LED горит всегда, не гасится | Перепутан GPIO, короткое на +3.3V | Проверь провода |
| Все LEDs не реагируют | WiFi не подключён, API недоступен | Проверь Serial Monitor (115200 baud) |
| windstation.local не открывается | mDNS не работает | Пробуй по IP: http://192.168.1.223 |
