# Задача 02: Настройка boost-модулей

## Промпт для новой сессии
```
Читай tasks/02-boost-config.md и выполни задачу шаг за шагом.
Источники истины: CLAUDE.md, bom-photos.md.
```

## Статус
- Блокеры: нужен паяльник Alientek T90B + мультиметр UT33A+
- Предыдущая задача: 01 (независима, можно делать параллельно)

## Цель
Настроить оба boost-модуля на правильные пресеты и подтвердить напряжения мультиметром.
**Это самая критичная задача — неправильный пресет сожжёт датчик мгновенно.**

## Компоненты
| Компонент | Назначение |
|-----------|-----------|
| Mini Boost MT3608 HW-085 × 2 | Boost#1 → 12V, Boost#2 → 5V |
| Паяльник Alientek T90B, жало C245-KU BK | Пайка падов A/B |
| Флюс ZJ-18 | Обязательно при пайке SMD |
| Мультиметр UNI-T UT33A+ | Проверка напряжений |
| USB 5V адаптер + кабель | Входное питание для тестирования |
| Dupont провода M-M × 4 | Временное подключение |

## Устройство boost-модуля HW-085
```
    OUT+ ──┤ ⦿            ⦿ ├── IN+
           │   ┌──┐          │
           │   │  │ дроссель  │
           │   └──┘          │
           │  ┌────────┐     │
           │  │ MT3608 │     │
           │  └────────┘     │
           │   ●A   ●B       │   ← ДВА ПАДА — выбор пресета
    OUT− ──┤ ⦿            ⦿ ├── IN−
```

## Таблица пресетов (пады A и B)

| Пад A | Пад B | Напряжение OUT | Модуль |
|-------|-------|----------------|--------|
| открыт | открыт | **5V** | Boost **#2** (батарея → шина) |
| замкнут | замкнут | **12V** | Boost **#1** (шина → датчик) |

- **Замкнут** = пайные пятачки соединены каплей припоя
- **Открыт** = пятачки чистые, между ними пространство

> ⚠️ Заводская поставка: как правило оба пада замкнуты = 12V.
> **Всегда проверяй мультиметром — не доверяй маркировке.**

## Настройка Boost#1 → 12V

**Цель:** оба пада A и B замкнуты.

### Шаг 1 — Проверить текущий пресет
1. Подключи: USB 5V адаптер → dupont → IN+/IN− boost-модуля
2. Мультиметр: режим **V⎓** (авторежим, один поворот)
3. Щупы: красный → OUT+, чёрный → OUT−
4. Прочитай напряжение

### Шаг 2 — Если уже 12V: ничего не делать
Пометь маркером **«#1 12V»** и переходи к Boost#2.

### Шаг 3 — Если НЕ 12V: паяй пады
1. Паяльник T90B: температура **330°C**, жало C245-KU BK
2. Нанеси каплю флюса ZJ-18 на оба пада
3. Маленькая капля припоя на жало
4. Коснись пада A на 1-2 секунды — должна образоваться серебристая горка
5. То же для пада B
6. Повтори замер — должно быть 12.0 ± 0.3V

## Настройка Boost#2 → 5V

**Цель:** оба пада A и B открыты.

### Шаг 1 — Проверить текущий пресет
1. Подключи: USB 5V адаптер → IN+/IN− boost-модуля (тот же способ)
2. Мультиметр → OUT+/OUT−
3. Прочитай напряжение

### Шаг 2 — Если уже 5V: ничего не делать
Пометь маркером **«#2 5V»**.

### Шаг 3 — Если НЕ 5V (скорее всего 12V с завода): открой пады
1. Паяльник 330°C, жало C245-KU BK
2. Нанеси флюс на пад A (флюс разжижает припой)
3. Прикоснись жалом к паду — припой расплавится и соберётся на жало
4. Убери жало одним движением
5. Осмотри: между пятачками пада должно быть видно пространство (не соединены)
6. Повтори для пада B
7. Замер: должно быть 5.0 ± 0.2V

## Итоговая проверка
| Модуль | Вход | Ожидаемый OUT | Допуск |
|--------|------|--------------|--------|
| Boost#1 (пометить «#1 12V») | 5V USB | **12.0V** | ±0.3V |
| Boost#2 (пометить «#2 5V») | 5V USB | **5.0V** | ±0.2V |

> ⚠️ Если boost#1 выдаёт НЕ 12V — НЕ ПОДКЛЮЧАЙ К НЕМУ ДАТЧИК.
> Датчик питается от boost#1. Неверное напряжение = датчик сгорел.

## Если не работает
| Симптом | Причина | Решение |
|---------|---------|---------|
| OUT = то же что IN (не повышает) | Нет питания | Проверь соединение IN+/IN− |
| После пайки напряжение не изменилось | Пады не замкнулись/не разомкнулись | Осмотри под лупой, повтори |
| OUT > 15V | Пады залиты, клон с нестандартной таблицей | Открой все пады, проверь снова |
| Модуль греется без нагрузки | Нормально (MT3608 греется), но не должен жечь палец | Если обжигает — КЗ, отключи |

- [ ] Boost#2 = 5.0 ± 0.2V, помечен «#2 5V»
- [ ] Оба модуля подписаны маркером
