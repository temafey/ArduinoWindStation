# KiCad: замена верхнего 15 kΩ на 10 kΩ + 5 kΩ (в серии)

Цель: верхнее плечо обоих сигнальных делителей теперь **10 kΩ + 5 kΩ последовательно** (= 15 kΩ, коэффициент делителя ×2.5 не меняется — прошивку `SIGNAL_DIVIDER_RATIO=2.5` НЕ трогаем). Причина: в наборе нет резистора 15 kΩ.

Итоговые цепи (нетлист):
- Скорость: `SPEED_SIG → R1(10k) → SPEED_MID → R12(5k) → SPEED_ADC → R2(10k) → GND`; конденсатор `C3` на `SPEED_ADC`.
- Направление: `DIR_SIG → R3(10k) → DIR_MID → R13(5k) → DIR_ADC → R4(10k) → GND`; конденсатор `C4` на `DIR_ADC`.
- Новые цепи: `SPEED_MID` = {R1.2, R12.1}; `DIR_MID` = {R3.2, R13.1}.

> Важно: эта схема соединяет делитель **по именам цепей (net labels)**, а не только геометрией.
> R1.низ и R2.верх сейчас оба помечены меткой `SPEED_ADC` — поэтому вставить R12 можно, **не двигая R1/R2**:
> достаточно переименовать одну метку и добавить R12, помеченный двумя нужными цепями.

Текущее (что видно в схеме): R1 и R3 = `15k`; R2, R4 = `10k`; посадочное место всех —
`Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P10.16mm_Horizontal`. Свободные позиции — R12, R13.

---

## 0. Перед началом
1. Сохрани всё в KiCad (Ctrl-S в редакторах). Файлы `.lck` показывают, что проект открыт — работай в открытом KiCad, не редактируй файлы снаружи.
2. Открой **Schematic Editor** (eeschema).
3. (На всякий случай) сделай копию проекта — уже есть бэкап `WindStation.kicad_sch.bak-packminus`; можешь сделать ещё один вручную.

## 1. Поменять номиналы верхних резисторов
1. Двойной клик по **R1** → поле **Value**: `15k` → `10k` → OK.
2. Двойной клик по **R3** → **Value**: `15k` → `10k` → OK.

(R2 и R4 остаются `10k` — не трогай.)

## 2. Канал СКОРОСТИ — вставить R12 (5 kΩ)
1. Найди метку цепи **`SPEED_ADC`, что стоит на НИЖНЕМ выводе R1** (верхняя из двух меток SPEED_ADC у делителя, ближе к R1).
   Двойной клик по ней → переименуй в **`SPEED_MID`** → OK.
   *(Метку `SPEED_ADC` на ВЕРХНЕМ выводе R2 оставь как есть — это и есть узел к GPIO34 и C3.)*
2. Поставь новый резистор (`A` → выбери `Device:R`), помести в свободном месте рядом с делителем.
3. Двойной клик по нему:
   - **Reference** = `R12`
   - **Value** = `5k`
   - **Footprint** = `Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P10.16mm_Horizontal` (как у R1)
4. Повесь метки цепей на его выводы (инструмент «Add Net Label», клавиша `L`):
   - на один вывод R12 → метка **`SPEED_MID`**
   - на другой вывод R12 → метка **`SPEED_ADC`**
   Подведи короткие проводки от выводов R12 к меткам, если нужно (`W` — провод).

Теперь цепь замкнулась: R1(10k).низ = `SPEED_MID` → R12(5k) → `SPEED_ADC` = R2(10k).верх + C3 + GPIO34. ✔

## 3. Канал НАПРАВЛЕНИЯ — вставить R13 (5 kΩ)
Точно так же:
1. Метку **`DIR_ADC` на НИЖНЕМ выводе R3** переименуй в **`DIR_MID`**.
   (`DIR_ADC` на верхнем выводе R4 — оставь.)
2. Новый резистор: **R13**, **5k**, тот же footprint.
3. Метки на его выводы: **`DIR_MID`** и **`DIR_ADC`**.

## 4. Проверка схемы
1. **Tools → Annotate Schematic** (если R12/R13 не проставились автоматически — обычно ставить вручную достаточно).
2. **Inspect → Electrical Rules Checker (ERC)** → Run.
   Ожидаемо чисто. Если ERC ругается «label not connected» — значит метка `SPEED_MID`/`DIR_MID` встречается только один раз: проверь, что она есть И на выводе R1(R3), И на выводе R12(R13). Каждая из `SPEED_MID`/`DIR_MID` должна встречаться ровно 2 раза.
3. Сверься с каноном (`../wind-station-schematic.md`, §3): 
   - `SPEED_MID` = ровно {R1.2, R12.1}; `SPEED_ADC` = {R12.2, R2.1, C3.1, ESP32.GPIO34}.
   - `DIR_MID` = ровно {R3.2, R13.1}; `DIR_ADC` = {R13.2, R4.1, C4.1, ESP32.GPIO35}.

## 5. Перенос на плату (PCB)
1. **Tools → Update PCB from Schematic** (F8) → Update.
   Добавятся два новых футпринта **R12** и **R13** (значения R1/R3 обновятся на 10k).
2. В **PCB Editor** (pcbnew):
   - Размести R12 рядом с R1 (короткая дорожка R1.pad2 → R12.pad1 = цепь `SPEED_MID`).
   - Размести R13 рядом с R3 (аналогично `DIR_MID`).
   - **Удали старую дорожку**, которая шла от R1.pad2 напрямую в кластер `SPEED_ADC` (к R2/C3/GPIO34): теперь R1.pad2 идёт ТОЛЬКО в R12.pad1. Аналогично R3.pad2 → только R13.pad1.
   - Проведи: R12.pad2 → кластер `SPEED_ADC` (R2, C3, GPIO34). R13.pad2 → кластер `DIR_ADC` (R4, C4, GPIO35).
3. **Inspect → Design Rules Checker (DRC)** → Run. Убедись, что нет unconnected/незамкнутых `SPEED_MID`/`DIR_MID`.

## Итог
- Схема: R1,R3 = 10k; добавлены R12,R13 = 5k; новые цепи SPEED_MID, DIR_MID; конденсаторы C3/C4 без изменений.
- Плата: два новых резистора разведены, старые дорожки R1.2/R3.2 перенаправлены через 5k.
- Прошивка: без изменений (коэффициент 2.5 сохранён физически).
